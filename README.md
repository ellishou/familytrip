## 已確定的決策

| 項目 | 決定 | 理由 |
|---|---|---|
| 成員 | 3 大 1 小（68、66、36、9 歲），36 歲負責開車 | — |
| 航班 | 樂桃 MM926（11/5 15:20 → 17:50）、MM925（11/9 13:35 → 14:20） | 從原本的 JTA 10:15 改搭這班，長輩從高雄上來不用早起 |
| 住宿 | 東急 STAY 沖繩那霸，2 間房 × 4 晚 | 全程不換飯店；房 A 爸媽，房 B 我和小孩 |
| 11/6 | Klook #134350 北部一日遊：萬座毛 → 古宇利島 → 美麗海 → 美國村 | 不用自己開北部長途；中文導遊、含門票 |
| 交通 | 頭尾 7 人座專車接送，中間租 Fit 級小車 | 比全程租 7 人座省約 NT$4,000～5,500 |
| 租車 | 沖繩行腳租車（小祿站），11/7 09:00 取車 → 11/8 18:00 還車 | 不選 K car（後座擠、上高速吃力）；小祿離飯店單軌約 6 分鐘 |
| 停車 | 只停 11/7 一晚，¥1,000 | 2026/7 實際入住價：1 晚 ¥1,000、2 晚 ¥1,800 |
| 長輩 | 每段步行不超過 30 分鐘 | 不排玉泉洞；Day 3 拿掉奧武島與知念岬（車程長），改走瀨長島 + PARCO CITY；Day 4 以港川外人住宅取代美國村 |
