## ✈️ 機票：還沒決定，有兩種情境

長輩可能**從高雄直飛**，所以先不訂票，行程兩種情境都走得通。

| | 情境一 · 全家同班機 | 情境二 · 長輩從高雄直飛 |
|---|---|---|
| 長輩怎麼到 | 前一天北上，建議 11/4 住桃園機場附近 | KHH → OKA 直飛，不用北上、不用早起 |
| 抵達 | 四個人一起 | **兩批人時間不同，要在那霸機場會合** |
| 費用 | 多一筆高鐵 + 桃園住宿（NT$5,700–7,700） | 那筆省下來，但機票可能較貴 |

**會合方式**：那霸機場入境大廳（國際線到達出口），誰先到誰等；班機號碼和落地時間放同一個群組。
時間差超過 2 小時的話，先到的先去飯店 check in。路線 B 取車要配合長輩的落地時間。

目標時段維持「中午前後抵達、傍晚離開」。可查：樂桃、虎航、星宇、長榮、華航、日本越洋（JTA/JAL）。
原本的樂桃 MM926 / MM925 時段不符，已不列入。
