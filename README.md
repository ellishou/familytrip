## 已確定的決策

| 項目 | 決定 | 理由 |
|---|---|---|
| 成員 | 3 大 1 小（68、66、36、9 歲），36 歲負責開車 | — |
| 航班 | 樂桃 MM926（11/5 15:20 → 17:50）、MM925（11/9 13:35 → 14:20） | 長輩從高雄上來不用早起 |
| 節奏 | **白天跑行程，傍晚就進飯店，晚上不開車** | 長輩才不會太累 |
| 住宿 | 小祿 2 晚 → 美國村 1 晚 → 國際通 1 晚 | 頭尾靠機場與單軌、中間住海邊；11/6 巴士團日不搬行李 |
| 11/6 | Klook #134350 北部一日遊：萬座毛 → 古宇利島 → 美麗海 → 美國村 | 長途交給巴士司機，自己不用開北部 |
| 11/7 | 瀨長島 → PARCO CITY → 傍晚進美國村 | 拿掉奧武島、知念岬（車程長、繞路） |
| 租車 | 沖繩行腳租車（小祿站），11/7 09:00 取 → 11/8 約 16:40 還 | 租車行就在 Y's Inn 旁，取車不用拉行李跑遠 |
| 車型 | **Freed / Sienta 級** | 11/7、11/8 行李都在車上，Fit 裝不下；也不選 K car |
| 送機 | 11/9 改搭單軌（縣廳前 → 機場約 15 分） | 住國際通，單軌很近，省一趟專車 |
| 長輩 | 每段步行不超過 30 分鐘 | 不排玉泉洞；Day 4 以港川外人住宅取代美國村 |
