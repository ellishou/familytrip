## 這趟的樣子

**2027/1/14（四）– 1/18（一）**　·　**4 大 1 小**：68、66、41（哥）、36（我）、9（小孩）

```
全員台北同班樂桃 → 小祿 1 晚 → 美國村 2 晚 → 國際通 1 晚 → 第 2 天才取車
```

- **駕駛 2 人**（41 + 36），可輪流開
- **第一天不租車**：住小祿，各自搭計程車進飯店（不走單軌，小祿站電梯只有一座）
- **全程自駕**，不參加巴士團

## ⚠️ 日本退稅新制（2026/11/1 起）

- 改成**先付含稅價、出境時在機場海關退**
- 🚫 **退稅品出境前不能拆封、不能使用** —— 拆了就退不了
- 退稅品**不能先托運**，到機場要**先退稅再報到**
- 1/18 我們 13:40 到機場、16:50 起飛，有 3 小時緩衝

## 費用概算

**每人 NT$24,700 – 33,600**（5 人合計 NT$123,500 – 168,000）。抓整數**每人準備 NT$35,000**就很夠。明細見 `行程.md`。

住宿（哥單人房）、長輩高鐵、小孩餐費這三項沒辦法真的平均分，結算時建議機票各付各的、其餘共同支出記帳後再分。
