## 這趟的樣子

```
全員從台北同班機 → 美國村住 2 晚 → 國際通住 2 晚 → 全程自駕
```

## 🚗 租車重點（依 2025 / 2026 兩次實際訂單）

- **24 小時制、不足一天進位** → `1/14 13:35 取 → 1/18 13:00 還` = 計費 4 天
  - 超過 13:35 還車就跳第 5 天；**提前還車尾款不退**
- **機場和小祿站接駁免費**，但**預訂時就要告知**讓工作人員登記
  - 機場接：國際線施工期間改在**國內線 3 樓 5 號出口**，用 Line / WhatsApp 通知
  - 實績：12:20 落地 → 13:00 取到車
- **報價（4 天，含保險 ¥8,800 + ETC ¥3,700）**
  - S 級 5 人座 ¥38,500／SUV 5 人座 ¥50,500／**新款 SIENTA 7 人座 ¥56,500**
  - 1 月屬一般時期（¥11,000／天），冬季加價 12/23–1/3 剛好避開
  - SIENTA 標示：最多 7 人、**建議 4 人、推薦行李 3 件** → 我們 5 人偏緊，要再問更大的廂型車
- **證件（兩位駕駛都要，全部正本）**：護照、台灣**汽車**駕照、日文譯本；地址不符要帶身分證
- **取消**：7 天前免費 → 6–3 天 20% → 1–2 天 30% → 當日 50%／保留車輛全額
  - ⚠️ **日期最好 2027/1/7 前定案**
- 營業所：沖繩縣那霸市金城 3-8-11-1F-2 號｜[地圖](https://goo.gl/maps/m9vUgWxW9kEke2UX6)

## ⚠️ 自駕取代巴士團的代價

- **1/15 全天車程約 3 小時 25 分**，回程高速一段就 1 小時 20 分
- 1 月日落約 18:00 → **16:00 沒離開水族館就會摸黑開高速**
- 北部冬天風大，萬座毛、古宇利島體感很冷
- 美麗海門票要自己買（建議網路先買）
- 💡 覺得太硬的備案：**放棄古宇利島**（省約 50 分鐘車程），或那天改回 Klook 巴士團
