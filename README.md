## 已確定的決策

| 項目 | 決定 | 理由 |
|---|---|---|
| 成員 | 3 大 1 小（68、66、36、9 歲），36 歲負責開車 | — |
| 節奏 | **白天跑行程，傍晚進飯店，晚上不開車** | 長輩才不會太累 |
| 航班時段 | 去程**中午抵達**、回程**傍晚起飛** | 第一天和最後一天都變成可用的整天 |
| 巴士團 | Klook #134350 北部一日遊：萬座毛 → 古宇利島 → 美麗海 → 美國村 | 長途交給巴士司機，自己不用開北部 |
| 租車 | 沖繩行腳租車（小祿站） | 離 Y's Inn／單軌都近 |
| 車型 | **Freed / Sienta 級** | 行李要上車，Fit 裝不下；也不選 K car |
| 景點取捨 | 拿掉奧武島、知念岬、玉泉洞 | 車程長、繞路、步行超過 30 分鐘 |

## ⚠️ 航班改時段的連帶影響

- **MM926 / MM925 不能用了**，要重選航班（樂桃、虎航、星宇、長榮、華航、日本越洋都有 TPE–OKA）
- 中午抵達 = 約 09:30 起飛 = 07:30 報到 = 長輩要搭約 **05:15** 的左營高鐵
  → **建議 11/4 晚上先住桃園機場附近**，費用已列入概算
- 回程約 19:20 落地，長輩轉高鐵回高雄約 22:30 到家，末班車來得及但偏晚
- 機票概算區間變寬，因為中午抵達的時段通常不是最便宜的廉航班次
