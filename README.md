## 已確定的決策

| 項目 | 決定 | 理由 |
|---|---|---|
| 日期 | **11/12（四）– 11/16（一）**，比原訂晚一週 | 原本的 11/4–11/5 撞到小孩考試 |
| 節奏 | **白天跑行程，傍晚進飯店，晚上不開車** | 長輩才不會太累 |
| 分批飛 | 桃園 3 人（41／36／9）+ **高雄直飛 2 人（爸媽）** | 長輩不用北上、不用早起、省一晚桃園住宿 |
| 航班時段 | 去程中午抵達、回程傍晚起飛 | 第一天和最後一天都變成可用的整天 |
| 租車 | 沖繩行腳（小祿營業所），**全程 4 天** | 機場接駁免費；保險 + ETC 是固定成本，租越多天越攤薄 |
| 車型 | **新款 SIENTA（7 人座）** | 第三排折下來 = 5 座 + 行李空間；只比 SUV 貴 ¥6,000 |
| 房間 | **每段 3 間** | 多一位成員 |
| 巴士團 | Klook #134350 北部一日遊 | 長途交給巴士司機，自己不用開北部 |
| 景點取捨 | 拿掉奧武島、知念岬、玉泉洞 | 車程長、繞路、步行超過 30 分鐘 |

## 🚗 租車重點（依 2025 / 2026 兩次實際訂單）

- **24 小時制、不足一天進位** → 這次抓 `11/12 13:00 取 → 11/16 13:00 還` = 剛好 4 天
  - 超過 13:00 還車就跳第 5 天；**提前還車尾款不退**
- **機場和小祿站接駁免費**，但**預訂時就要告知**讓工作人員登記
  - 機場接：國際線施工期間改在**國內線 3 樓 5 號出口**，用 Line / WhatsApp 通知
  - 實績：12:20 落地 → 13:00 取到車
- **報價（4 天，全包含保險 ¥8,800 + ETC ¥3,700）**
  - S 級 5 人座 **¥38,500**
  - SUV 5 人座 **¥50,500**
  - **新款 SIENTA 7 人座 ¥56,500**（¥11,000／天 × 4，11 月屬一般時期最低價）
  - SIENTA 標示：最多 7 人、**建議 4 人、推薦行李 3 件** → 我們 5 人偏緊，要再問更大的廂型車
- **證件（兩位駕駛都要，全部正本）**：護照、台灣**汽車**駕照、日文譯本；地址不符要帶身分證
- **取消**：7 天前免費 → 6–3 天 20% → 1–2 天 30% → 當日 50%／保留車輛全額
  - ⚠️ **日期和路線最好 11/5 前定案**
- 營業所：沖繩縣那霸市金城 3-8-11-1F-2 號｜[地圖](https://goo.gl/maps/m9vUgWxW9kEke2UX6)
